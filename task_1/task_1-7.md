<section class="theory" markdown="1">

## Теоретические сведения
{: .section__title}

Практически любая программа устроена по одному шаблону: **ввод → обработка → вывод**. Данные приходят из внешнего мира, над ними выполняются вычисления, результат отдаётся человеку или записывается в файл. Каркас не меняется весь семестр — усложняется только середина: в неё добавятся ветвления (тема 3), циклы (тема 4), функции (тема 7). К концу семестра вводом станет файл FASTA, обработкой — подсчёт GC-состава и поиск мотивов, выводом — таблица.

Сегодня ввод — функция `input()`, вывод — функция `print()` и f-строки. Функцией `print()` вы пользуетесь с task 1-0, но пока только в простейшей форме; здесь разберём её полностью. Главное, что нужно запомнить об `input()`: **она всегда возвращает строку**. Три из четырёх типичных ошибок ввода — следствия этого факта.

</section>

## <span class="subsection__num">1.</span> `print()` печатает не одно значение
{: .subsection__title}

<div class="syntax">print(значение, значение, ..., sep=' ', end='\n')</div>

- Значений может быть сколько угодно (в том числе ни одного), через запятую. Они могут быть разных типов: `print()` сам превращает каждое в текст, `str()` не нужен.
- `sep` (separator) — что ставить **между** значениями. По умолчанию один пробел.
- `end` — чем **закончить** вывод. По умолчанию `'\n'` — перевод строки, поэтому следующий `print()` печатает с новой строки.
- `sep` и `end` указывают после значений, по имени: `sep='-'`. Это именованные аргументы (task 1-6); если их не указать, действуют значения по умолчанию.
- `print()` без значений выводит пустую строку.

<article class="example" markdown="1">

### Пример 1. Несколько значений, `sep` и `end`
{: .example__title}

Файл `print_demo.py`:

```python
print('Pay:', 96.25)
print('Длина:', 150, 'нт')
print('GC:', 0.5, True)
print('A', 'T', 'G', sep='')
print('A', 'T', 'G', sep='-')
print('S1', 'S2', 'S3', sep=', ')
print('Загрузка', end='... ')
print('готово')
print()
print('конец')
```

```text
Pay: 96.25
Длина: 150 нт
GC: 0.5 True
ATG
A-T-G
S1, S2, S3
Загрузка... готово

конец
```
{: .output}

<div class="analysis" markdown="1">

Разбор
{: .analysis__title}

- Строки 1–3: значения разных типов выведены через пробел; число и логическое значение превращены в текст автоматически.
- Строка 4: `sep=''` — пустой разделитель, буквы склеились.
- Строки 5–6: разделитель может быть любой строкой, в том числе из нескольких символов.
- Строки 7–8: первый `print()` закончил вывод не переводом строки, а текстом `'... '`, поэтому второй продолжил ту же строку.
- Строка 9: пустая строка в выводе.

</div>

</article>

## <span class="subsection__num">2.</span> Специальные символы
{: .subsection__title}

<div class="overview" markdown="1">

Обзорно
{: .overview__label}

Здесь показаны только самые нужные специальные символы. Подробно запись строк изучается в теме 2 «Строки и текстовые данные».
{: .overview__ref}

Внутри кавычек обратная косая черта `\` вместе со следующим символом обозначает один специальный символ (task 1-2).

| Запись | Символ |
|---|---|
| `\n` | перевод строки |
| `\t` | табуляция: переход к следующей позиции табуляции; удобна для таблиц |
| `\\` | сама обратная косая черта |
| `\'` и `\"` | кавычка, которая не завершает строку |

Каждая такая пара — **один** символ: `len('A\tB')` равно 3.

</div>

<article class="example" markdown="1">

### Пример 2. Специальные символы
{: .example__title}

Файл `escapes.py`:

```python
print('Строка 1\nСтрока 2')
print('Образец\tДлина')
print('S1\t150')
print('C:\\Users\\student')
print('5\'-конец')
print("Он сказал: \"готово\"")
print(len('A\tB'))
```

```text
Строка 1
Строка 2
Образец	Длина
S1	150
C:\Users\student
5'-конец
Он сказал: "готово"
3
```
{: .output}

<div class="analysis" markdown="1">

Разбор
{: .analysis__title}

- Строка 1: один `print()` вывел две строки.
- Строки 2–3: табуляция выравнивает второй столбец по позиции табуляции (обычно кратной 8 символам), поэтому `Длина` и `150` оказались друг под другом.
- Строки 5–6: кавычка того же вида, что и ограничивающие строку, записана через `\`. Проще выбрать кавычки другого вида (task 1-4), но знать такую запись полезно.

</div>

## <span class="subsection__num">3.</span> Подставить значение в текст: f-строки
{: .subsection__title}

Склеивать текст и числа знаком `+` неудобно: каждое число нужно превращать в строку, иначе `TypeError`.

<article class="example" markdown="1">

### Пример 3. Склейка с числом
{: .example__title}

Файл `concat_number.py`:

```python
print('I am number ' + 42)
```
{: .code-block--bad}

```text
Traceback (most recent call last):
  File "C:\Users\student\Desktop\python_work\concat_number.py", line 1, in <module>
    print('I am number ' + 42)
          ~~~~~~~~~~~~~~~^~~~
TypeError: can only concatenate str (not "int") to str
```
{: .output .output--error}

Файл `concat_fixed.py`:

```python
print('I am number ' + str(42))
print(f'I am number {42}')
```
{: .code-block--good}

```text
I am number 42
I am number 42
```
{: .output}

Первая строка работает, но громоздка. Вторая — <dfn>f-строка</dfn> — снимает целый класс ошибок с преобразованием типов.

</article>

<div class="overview" markdown="1">

Обзорно
{: .overview__label}

Здесь показаны подстановка значения и формат вещественного числа. Подробно форматирование строк изучается в теме 2 «Строки и текстовые данные».
{: .overview__ref}

<div class="syntax">f'текст {выражение} текст'<br/>f'текст {выражение:.2f} текст'</div>

- Перед открывающей кавычкой ставится буква `f`.
- В фигурных скобках — любое выражение: имя переменной, вычисление, вызов функции. Python вычисляет его и подставляет результат в текст.
- После двоеточия можно указать формат. `:.2f` — вещественное число с двумя знаками после точки; `:.1f` — с одним, `:.0f` — без дробной части. Запись `:0.2f` из лекции означает то же, что `:.2f`.
- Округление в формате подчиняется тем же правилам, что `round()` (task 1-6): к чётному при точной половине, с учётом того, как число хранится.
- Результат f-строки — обычная строка типа `str`. Исходное число при этом не меняется: форматирование — только для показа.

</div>

<article class="example" markdown="1">

### Пример 4. f-строки
{: .example__title}

Файл `fstrings.py`:

```python
camels = 42
print(f'I have spotted {camels} camels.')
x = 123.456
print(f'Value is {x:0.2f}')
print(f'Value is {x:.1f}')
gc = 13 / 30
print(f'GC-состав: {gc:.3f}')
print(f'В процентах: {gc * 100:.1f} %')
print(f'Длина: {len("ATGGCC")} нт')
print(f'{2.675:.2f} {0.125:.2f} {2.5:.0f}')
print(type(f'{camels}'))
```

```text
I have spotted 42 camels.
Value is 123.46
Value is 123.5
GC-состав: 0.433
В процентах: 43.3 %
Длина: 6 нт
2.67 0.12 2
<class 'str'>
```
{: .output}

<div class="analysis" markdown="1">

Разбор
{: .analysis__title}

- Строка 2: значение `camels` подставлено в текст без `str()`.
- Строки 4–5: 123.456 показано с двумя и с одним знаком; значение `x` не изменилось.
- Строка 8: в скобках — вычисление `gc * 100`.
- Строка 9: в скобках — вызов функции. Строка внутри скобок записана в двойных кавычках, чтобы не путать её с одинарными кавычками f-строки.
- Строка 10: те же результаты, что у `round()` в task 1-6.
- Строка 11: f-строка — это `str`.

</div>

</article>

<div class="mistake" markdown="1">

Типичная ошибка: забыта буква `f`
{: .mistake__title}

Файл `no_f.py`:

```python
sample = 'S-17'
print('Образец {sample} готов')
print(f'Образец {sample} готов')
```
{: .code-block--bad}

```text
Образец {sample} готов
Образец S-17 готов
```
{: .output}

Без `f` фигурные скобки — обычные символы текста, и подстановки нет. Сообщения об ошибке тоже нет: это семантическая ошибка, заметная только по выводу.

</div>

## <span class="subsection__num">4.</span> `input()`: программа останавливается и ждёт
{: .subsection__title}

<div class="syntax">переменная = input('текст-приглашение')</div>

1. Программа печатает <dfn>приглашение</dfn> — текст, из которого человек узнаёт, что от него хотят. Перевода строки после приглашения нет: курсор остаётся в той же строке.
1. Программа стоит и ждёт — сколько угодно долго. Человек набирает текст.
1. Человек нажимает <kbd>Enter</kbd>. Функция возвращает набранный текст (без символа перевода строки), и программа идёт дальше.
{: .steps}

^

- `input()` **всегда возвращает строку** типа `str` — даже если набраны цифры.
- Если сразу нажать <kbd>Enter</kbd>, вернётся пустая строка `''`.
- Чтобы ввод оказался под вопросом, в конце приглашения ставят `\n`.
- Программа, которая «висит» сразу после запуска, чаще всего просто ждёт ввода. `input()` без приглашения — плохая программа, даже если она работает.
- При запуске из VS Code текст вводится в панели терминала, из PyCharm — в окне Run. Перед вводом щёлкните в этой панели мышью.

На этой странице текст, набранный человеком, выделен в выводе так: @@Anna@@.

<article class="example" markdown="1">

### Пример 5. Приглашение с переводом строки
{: .example__title}

Файл `greeting.py`:

```python
name = input('What is your name?\n')
print('Hello,', name)
```

```text
What is your name?
@@Anna@@
Hello, Anna
```
{: .output}

<div class="analysis" markdown="1">

Разбор
{: .analysis__title}

- Строка 1 печатает вопрос и переводит строку (`\n`), затем ждёт ввода. Человек набрал `Anna` и нажал <kbd>Enter</kbd> — нажатие <kbd>Enter</kbd> переводит курсор на следующую строку.
- Имя `name` привязано к строке `'Anna'`; строка 2 выводит два значения через пробел.

</div>

</article>

<article class="example" markdown="1">

{: .example__title}

Файл `always_str.py`:

```python

```


{: .analysis__title}

- Строка 3: склейка строк `'150' + '0'` дала `'1500'`, а не сложение.
- Строка 4: после `int()` получилось число, и сложение дало 160.

</div>

### Преобразуйте сразу при вводе
{: .block-title}

Если значение должно быть числом, преобразуйте его в той же строке, где вызываете `input()`: `int(input(...))` или `float(input(...))`. Вложенные вызовы выполняются изнутри наружу: сначала `input()` возвращает строку, затем `int()` превращает её в число. Если отложить преобразование, потом легко забыть, откуда пришло значение.

<article class="example" markdown="1">

### Пример 8. Человек ввёл не число
{: .example__title}

Тот же файл `speed_ok.py`, другой ввод:

```python

```

```text
Скорость центрифуги, тыс. об/мин: @@семнадцать@@
Traceback (most recent call last):

            ~~~^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

```
{: .output .output--error data-label="Вывод терминала (Python 3.13 и новее)"}

<div class="analysis" markdown="1">

Разбор
{: .analysis__title}

- Сценарий А — человек ввёл `17`: `int()` даёт 17, программа продолжается (пример 7).

- Полная обработка таких ситуаций — тема 9 «Файлы, исключения и сквозной проект семестра». Сегодня достаточно понимать причину.

<section class="subsection" id="s5" markdown="1">

## <span class="subsection__num">5.</span> Шаблон любой программы: ввод → обработка → вывод
{: .subsection__title}

<ol aria-label="Шаблон программы" class="flow">
<li class="flow__step"><span class="flow__title">Ввод</span><span class="flow__text">данные из внешнего мира; сегодня <code>input()</code>, дальше файлы и сеть</span></li>
<li class="flow__step"><span class="flow__title">Обработка</span><span class="flow__text">выражения над значениями; сегодня арифметика</span></li>
<li class="flow__step"><span class="flow__title">Вывод</span><span class="flow__text">результат человеку или в файл; сегодня <code>print()</code> и f-строки</span></li>
</ol>

### Пример 9. Собираем вместе
{: .example__title}

Программа из лекции: оплата по числу часов и ставке. Файл `pay.py`:

```python
hours = input('Enter Hours: ')
rate = input('Enter Rate: ')
pay = float(hours) * float(rate)
print(f'Pay: {pay}')
```

```text
Enter Hours: @@35@@
Enter Rate: @@2.75@@
Pay: 96.25
```
{: .output}

<div class="analysis" markdown="1">

Разбор
{: .analysis__title}

- **Ввод** (строки 1–2): два вопроса, две строки. Имена мнемоничные — программа читается как условие задачи.
- **Обработка** (строка 3): преобразование в числа, иначе `*` над строками не сработает (строку нельзя умножить на строку).
- **Вывод** (строка 4): f-строка, подстановка без склейки.
- Что здесь ещё не сделано: программа упадёт, если ввести буквы вместо числа (раздел 4), а результат не отформатирован — при других данных может появиться длинный «хвост» (task 1-6). Второе исправляется форматом `{pay:.2f}`.

## <span class="subsection__num">6.</span> Четыре симптома
{: .subsection__title}

| Что видите | Причина | Что делать |
|---|---|---|
| `TypeError` при арифметике | значение осталось строкой | преобразовать сразу при вводе |
| `ValueError: invalid literal` | во вводе не число | проверять данные до преобразования; вводить число |
| программа «висит» | `input()` ждёт, а приглашения нет | передать текст в `input()` |
| числа склеились: `3542` | `+` над строками — конкатенация | `int()` перед сложением |

Первые два симптома опознаются по первому слову последней строки сообщения. Три из четырёх — последствия одного факта: `input()` возвращает строку.

## Итоговое задание: калькулятор разведения <span class="level level--5">Уровень 5 · итоговое</span>

Файл: <span class="task__file">task\_1-7\_dilution.py</span>
{: .task__meta}

При разведении раствора выполняется равенство *C*<sub>1</sub> · *V*<sub>1</sub> = *C*<sub>2</sub> · *V*<sub>2</sub>, где *C*<sub>1</sub> — концентрация исходного раствора, *V*<sub>1</sub> — нужный объём исходного раствора, *C*<sub>2</sub> — нужная концентрация, *V*<sub>2</sub> — конечный объём. Объём буфера = *V*<sub>2</sub> − *V*<sub>1</sub>. Кратность разведения = *C*<sub>1</sub> / *C*<sub>2</sub>. Развести раствор можно, только если нужная концентрация не больше исходной.

Напишите программу, которая спрашивает *C*<sub>1</sub>, *C*<sub>2</sub> и *V*<sub>2</sub> (все — вещественные числа) и печатает расчёт. Вывод должен совпадать с примерами символ в символ.

```text

Кратность разведения: 4.0
Разведение возможно: True
------------------------------
C1 | C2 | V2
```

**Требования:**

1. Программа устроена по шаблону «ввод → обработка → вывод»: все вопросы — в начале, все вычисления — после них, весь вывод — в конце. Части разделены пустыми строками и комментариями.
1. Введённые значения преобразуются в числа сразу при вводе.
1. *V*<sub>1</sub> вычисляется как *C*<sub>2</sub> · *V*<sub>2</sub> / *C*<sub>1</sub> — в этом порядке действий.
1. Объёмы выводятся f-строками с двумя знаками после точки; кратность — без форматирования.
1. В программе использованы `print()` без значений, параметр `sep` (в двух последних строках) и параметр `end` (в строке «Разведение возможно»). Черта из 30 дефисов получается повторением строки.
1. Значение `True`/`False` — результат сравнения.
1. В конце файла ответьте комментарием: что не так с результатом примера 3 и какой инструмент понадобится, чтобы программа в такой ситуации не печатала бессмысленный расчёт (подсказка — тема 3).
